**Тема:** Запрос прав доступа wall и photos для приложения VK ID 54692110

Здравствуйте!

Прошу предоставить приложению VK ID «Позитивные новости» (ID 54692110) права доступа
`wall` и `photos`.

**Для чего.** Приложение обслуживает одно сообщество ВКонтакте — «Позитивные новости»
(https://vk.com/positivenus, id 233237778), администратором которого я являюсь. Оно
автоматически выкладывает на стену сообщества новости и ежедневную «Картину дня» с моего
сайта wildcar.org: короткий пересказ, одна иллюстрация и ссылка на страницу новости.
Другие пользователи, чужие сообщества и чужие стены приложение не затрагивает; токен
получает только один человек — администратор сообщества.

**Какие методы нужны.** `photos.getWallUploadServer`, `photos.saveWallPhoto`, `wall.post`
(от имени сообщества, `from_group=1`). Ключ доступа сообщества позволяет публиковать
только текст: `photos.getWallUploadServer` с ним отвечает ошибкой 27, поэтому без прав
`wall` и `photos` у пользовательского токена посты выходят без картинок.

**Объём.** 8–10 публикаций в сутки, около 30–50 вызовов API в сутки, до 1 500 в месяц.

**Как устроено технически.** Приложение серверное (конфиденциальное), запросы уходят с
одного фиксированного IP 208.92.227.90, авторизация — OAuth 2.1 + PKCE через VK ID,
токены продлеваются refresh-токеном. Адрес возврата: https://wildcar.org/auth/vk-id/.
Вход и обмен кода уже работают; токен с базовыми правами получен, `users.get` и
`groups.getById` отвечают, `photos.getWallUploadServer` — ошибкой 15 из-за отсутствия
прав в scope.
